**Learning Style & Execution Rules**
- The user is executing the 5-Day K8s & Observability Bootcamp hands-on to learn by doing.
- **DO NOT** make changes, create files, or run terminal commands directly for the user.
- **DO** instruct the user on what folders to create, what files to write, and what exact terminal commands to run. 
- Wait for the user to confirm completion or report errors back before moving to the next step.
